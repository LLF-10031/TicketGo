# TicketGo — 页面原型与视觉规范

> 版本：v0.2（改版）
> 布局参考：用户端 **B站式**、管理端 **Ant Design Pro 式**
> 配色：**大麦风**（主色 `#FF4B2B`）；登录页为**水墨国风特例皮肤**
> 可点击 HTML 原型：`TicketGo/prototype/`（纯手写 CSS，离线可开）

---

## 一、视觉规范

### 1.1 配色（大麦风 + 暖色调）
| 用途 | 值 | 说明 |
|---|---|---|
| 主色 | `#FF4B2B` | 按钮/价格/强调 |
| 主色渐变 | `#FF4B2B → #FF7A45` | Banner/头像/按钮 |
| 主色浅底 | `#FFF3EC` | 选中态/Tag |
| **页面底色** | `#FBF8F4`（暖白） | 与登录页统一暖调 |
| **暖米 / 暖杏**（登录） | `#FFF8EE → #FBE7CE` | 登录页背景渐变 |
| **暖褐墨**（登录） | `#5B4636` | 诗句/标题 |
| **朱砂**（印章） | `#C0392B` | 印章/朱砂点缀 |
| 文字主 | `#1A1A1A`；次 `#666`；弱 `#999` | — |
| 边框/分割 | `#EEE` / `#F5EFE6` | — |
| 状态 | 成功 `#38A169`；警示 `#FF7A1A`；售罄灰 `#999` | — |

### 1.2 字号与间距
| 元素 | 字号 | 说明 |
|---|---|---|
| 页标题 | 20–26px / 700 | — |
| 卡片标题 | 15px / 600 | 两行截断 |
| 正文 | 14px | — |
| 辅助 | 12–13px | 场馆/时间/角标 |
| 圆角 | 10px（卡片）/ 999px（搜索与按钮胶囊） | — |
| 阴影 | `0 2px 12px rgba(0,0,0,.06)`；hover `0 2px 12px rgba(255,75,43,.16)` | — |

### 1.3 组件视觉
- **按钮**：主按钮实心大麦色；次按钮浅底；胶囊用于搜索/CTA。
- **卡片**：白底 + **清晰的暖色边框 `#E8D9C5`** + 圆角 + 柔和阴影（边框分明、阴影收敛）；hover 上浮 + 边框转大麦浅色 `#FFD9C8`。
- **标签**：浅底圆角（6px），状态色区分。
- **头像**：36px 圆形渐变底 + 首字；hover 弹出用户卡片 + 下拉菜单。
- **边框规范（用户端）**：卡片/入口/订单卡/侧栏 `1px #E8D9C5`；Header/导航底边 `#E6D8C4`；输入框 `#E3D2BC`。

## 二、用户端布局（B站式）

### 2.1 全局结构
```
┌ Header（吸顶）Logo │ 圆角搜索框 │ 消息/订单/券 │ 头像▾ ┐
├ 主导航（水平Tab，选中大麦色下划线）                      ┤
├ 内容区（最大宽 1200px 居中）                            ┤
└ Footer                                               ┘
```

### 2.2 头像 / 昵称布局（借鉴 B站）
- 右上角 **36px 圆形头像**（渐变底 + 昵称首字）；未登录显示〔登录/注册〕。
- **hover**：弹出用户卡片（大头像 + 昵称 + "订单 3 · 券 2" + 快捷入口）。
- **点击/下拉菜单**：个人中心 / 我的订单 / 我的券包 / 设置 / 退出登录。

### 2.3 页面清单与要点
| 页面 | 布局要点 | 原型 |
|---|---|---|
| 登录/注册 | **水墨国风**：全屏水墨背景 + 花瓣动画 + 玻璃拟态卡片 + 书法体标题 | `login.html` |
| 首页 | 轮播 Banner + 分类快捷入口 + **演出卡片网格**（封面/角标/标题/场馆/价格） | `index.html` |
| 演出详情 | 左海报 + 右信息；场次选择 + 票档行；底部固定购票栏（免选座/选座） | `detail.html` |
| 订单列表 | **左菜单 + 右订单卡片**；状态色 + 支付倒计时 + 操作按钮 | `orders.html` |
| 秒杀抢票 | 顶部信息条 + 居中大按钮 + 开票倒计时 + 选券卡片 + 结果弹窗 | （见 04/08） |
| 选座 | 舞台 + SVG 座位图 + 右侧订单摘要 + 底部结算 | （见 04/08） |
| 券中心/我的券包 | 券卡片网格（图片/门槛/优惠/有效期）+ 状态 Tab | （见 08） |
| 个人中心 | 左菜单 + 右内容（头像/昵称/改密码） | （见 08） |

## 三、登录页 · 暖色水墨国风（特例皮肤）
- **背景**：**暖色渐变** `#FFF8EE → #FBE7CE`（暖米→暖杏）+ 极淡纸纹点阵 + **暖褐墨**淡影山峦（非冷色）。
- **右侧竖排书法水印**：诗句 **"此曲只应天上有，人间能得几回闻"**（`writing-mode: vertical-rl`，暖褐墨、低透明、轻微浮动动画）；右下角**朱砂小印章"票韵"**。
- **卡片（风格 A 雅致玻璃）**：暖白玻璃 `rgba(255,252,246,.82)` + `backdrop-filter: blur` + 圆角 20px + 暖色阴影；顶部**朱砂印章 Logo + 书法标题 + 墨色笔触分隔线**。
- **输入框**：左图标（📱/🔒）+ 描边式，聚焦大麦橙渐显 + 光晕。
- **按钮**：大麦橙渐变 + hover 上浮发光。
- **辅助行**：记住我 · 忘记密码；"+ 其他登录方式"分割线 + 第三方图标（占位）。
- **动效**：卡片淡入上浮；验证码 Tab 切换。
- ⚠️ 版权：仅用**免费商用**字库（Ma Shan Zheng / 站酷 / 思源），避免方正/汉仪商业字。

## 四、管理端布局（Ant Design Pro 式）
```
┌ 左固定侧栏(深色) ┐┌ 顶栏(面包屑 · 头像) ────────────┐
│ Logo            ││                              │
│ 演出管理 ●      ││ 筛选区: [关键词][状态][查询][+新建] │
│ 场次/票档       ││ 表格: 列... 操作(编辑/删除)      │
│ 优惠券模板      ││ 分页                          │
│ 订单管理        ││                              │
│ 库存管理        ││                              │
│ 数据看板        ││                              │
│ 系统设置        ││                              │
└─────────────────┘└──────────────────────────────┘
```
- **侧栏**：深色 `#1F2430`，选中项大麦色高亮。
- **顶栏**：面包屑 + 消息 + 头像。
- **CRUD 页**：筛选表单 + 表格 + 分页 + 新增（弹窗/抽屉）。
- 原型：`admin.html`。
