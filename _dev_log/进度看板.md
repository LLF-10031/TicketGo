## 运行说明（内存受限环境，务必按此启动）

### 结论
- 代码全部在**宿主机**运行；Docker 只跑基础设施。
- **10 个服务 + 6 个容器同时运行需要 ≥8GB 可用内存**；内存不足时会 `OutOfMemoryError: Metaspace`，服务被系统杀掉。
- 演示**核心链路**只需 6 个服务：`user / product / seckill / order / payment / gateway`（coupon/seat/cart/notification 可后补）。

### 启动顺序
1. 基础设施（只需三个即可跑核心链路）：
   `docker compose up -d mysql redis nacos`
   - 确认：`mysql 3307`、`redis 6379`、`nacos 8848/9848` 可连（WSL mirrored 模式下用 TcpClient 实测，不要只看 netstat）。
2. 服务（小堆 + 分批，逐个确认）：
   ```
   $env:JAVA_HOME="D:\JDK\jdk-21"
   java -Xms32m -Xmx128m -XX:MaxMetaspaceSize=160m -Xss256k -XX:+UseSerialGC -jar ticketgo-user/target/ticketgo-user-1.0.0.jar
   # 待其 Started 后，再起下一个：product → seckill → order → gateway → payment
   ```
3. 需要 Kafka/MinIO/Seata 时：`docker compose up -d kafka minio seata`（会额外占用 ~1GB，内存不足时请先腾出空间）。
4. 前端：`cd ticketgo-frontend && npm run dev`（proxy 到 8080）。
