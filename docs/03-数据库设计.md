# TicketGo — 演出/赛事票务抢票平台 — 数据库设计

> 版本：v0.1（草稿）
> 状态：基于已定决策，`[TBD]` 标记待定项

---

## 一、实体关系说明

```
user ─1:N─ order ─N:1─ product(演出)
product ─1:N─ session(场次) ─1:N─ ticket_tier(票档)
seat(座位) ─N:1─ session(场次)
order ─1:N─ order_item(子订单项)
order ─1:1─ payment(支付)
cart ─1:N─ cart_item(购物车项)
message_outbox(待发消息表) 独立
```

---

## 二、表结构

### 2.1 user（用户）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 雪花 ID |
| phone | VARCHAR(20) | 手机号，唯一 |
| password | VARCHAR(128) | BCrypt 加密，可空（验证码登录） |
| nick_name | VARCHAR(50) | 昵称 |
| icon | VARCHAR(255) | 头像 URL |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(phone)` 唯一索引。

### 2.2 product（演出）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| name | VARCHAR(200) | 演出名称 |
| category | VARCHAR(50) | 分类：演唱会/话剧/体育/展览 |
| description | TEXT | 简介 |
| poster | VARCHAR(500) | 海报 URL |
| status | TINYINT | 0=未上架 1=已上架 2=售罄 3=已结束 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(category, status)`、`(status, create_time DESC)`。

### 2.3 session（场次）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| product_id | BIGINT FK | 所属演出 |
| venue | VARCHAR(200) | 场馆 |
| show_time | DATETIME | 演出时间 |
| sale_start_time | DATETIME | 开票时间 |
| sale_end_time | DATETIME | 截止售票时间 |
| status | TINYINT | 0=待开票 1=售票中 2=售罄 3=已结束 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(product_id, show_time)`、`(sale_start_time, sale_end_time, status)`。

### 2.4 ticket_tier（票档）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| session_id | BIGINT FK | 所属场次 |
| name | VARCHAR(50) | 票档名，如"看台票"、"内场票" |
| price | DECIMAL(10,2) | 价格 |
| total_stock | INT | 总库存 |
| sold_stock | INT | 已售库存 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(session_id, price)`。

### 2.5 seat（座位）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| session_id | BIGINT FK | 所属场次 |
| tier_id | BIGINT FK | 所属票档 |
| row_no | VARCHAR(10) | 排号 |
| col_no | VARCHAR(10) | 座号 |
| status | TINYINT | 0=可售 1=锁定 2=已售 |
| lock_expire_at | DATETIME | 锁座超时时间，可空 |
| lock_token | VARCHAR(64) | 锁座 token，CAS 用 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(session_id, tier_id, status)`、`(lock_expire_at)`。

### 2.6 order（订单）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 雪花 ID |
| order_no | VARCHAR(64) | 订单号，唯一 |
| user_id | BIGINT FK | 下单用户 |
| **order_type** | TINYINT | **1=票订单(TICKET), 2=券订单(COUPON)** |
| session_id | BIGINT FK | 所属场次，可空（券订单为空） |
| total_amount | DECIMAL(10,2) | 总金额 |
| status | TINYINT | 0=待支付 1=已支付 2=已取消 3=已退款 4=已完成 |
| pay_expire_at | DATETIME | 支付截止时间 |
| paid_at | DATETIME | 支付时间，可空 |
| cancelled_at | DATETIME | 取消时间，可空 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(order_no)` 唯一索引、`(user_id, status, create_time DESC)`、`(status, pay_expire_at)`。

**分表**：按 `user_id` 哈希分表（如 64 张），路由规则第一天定，单机配置单表，上云改配置即生效。

### 2.7 order_item（子订单项）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| order_id | BIGINT FK | 所属订单 |
| tier_id | BIGINT FK | 票档 |
| seat_id | BIGINT FK | 座位，可空（免选座时为空） |
| price | DECIMAL(10,2) | 单价 |
| quantity | INT | 数量 |
| create_time | DATETIME | — |

**索引**：`(order_id)`。

### 2.8 payment（支付）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| order_id | BIGINT FK | 唯一 |
| amount | DECIMAL(10,2) | 支付金额 |
| pay_type | VARCHAR(20) | 支付方式，Mock |
| status | TINYINT | 0=待支付 1=支付成功 2=支付失败 3=已退款 |
| trade_no | VARCHAR(128) | 支付流水号，可空（Mock 模拟） |
| paid_at | DATETIME | 支付时间，可空 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(order_id)` 唯一索引。

### 2.9 cart（购物车）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| user_id | BIGINT FK | 所属用户 |
| session_id | BIGINT FK | 场次 |
| tier_id | BIGINT FK | 票档 |
| seat_id | BIGINT FK | 座位，可空 |
| quantity | INT | 数量 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(user_id, session_id)`。

### 2.10 message_outbox（待发消息表，本地消息表方案）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| biz_key | VARCHAR(128) | 业务唯一键（如订单号） |
| topic | VARCHAR(100) | Kafka topic |
| message_body | TEXT | 消息体 JSON |
| status | TINYINT | 0=待发送 1=已发送 2=失败 |
| retry_count | INT | 重试次数 |
| max_retry | INT | 最大重试次数 |
| next_retry_at | DATETIME | 下次重试时间 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(status, next_retry_at)`、`(biz_key)` 唯一索引。

### 2.11 coupon_template（优惠券模板）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| name | VARCHAR(100) | 券名称 |
| type | VARCHAR(20) | 券种：full_reduce / discount / immediate |
| threshold_amount | DECIMAL(10,2) | 使用门槛（满 X），0=无门槛 |
| discount_amount | DECIMAL(10,2) | 满减/立减面额 |
| discount_rate | DECIMAL(5,4) | 折扣率（如 0.8000） |
| max_discount | DECIMAL(10,2) | 折扣封顶，可空 |
| scope_type | TINYINT | 适用范围：0=全部 1=指定演出 |
| scope_product_ids | VARCHAR(500) | 限定演出 ID 列表（JSON/逗号） |
| valid_type | TINYINT | 0=固定区间 1=领取后N天 |
| valid_start | DATETIME | 固定生效开始，可空 |
| valid_end | DATETIME | 固定生效结束，可空 |
| valid_days | INT | 领取后有效天数 |
| **stock_type** | TINYINT | **0=限量 1=不限量** |
| total_qty | INT | 总量（限量时） |
| **per_user_limit** | INT | **每人限购数（管理端配置；限量券=1，不限量券=N）** |
| acquire_type | TINYINT | 获取方式：0=领取(免费) 1=购买 |
| price | DECIMAL(10,2) | 购买价（acquire_type=购买时） |
| **image_url** | VARCHAR(500) | 券图片 URL，可空（复用图片管道 biz_type=coupon） |
| status | TINYINT | 0=草稿 1=已上架 2=已结束 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(status, create_time DESC)`、`(type)`。

### 2.12 user_coupon（用户券）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| user_id | BIGINT FK | 所属用户 |
| template_id | BIGINT FK | 券模板 |
| status | TINYINT | 0=未用 1=锁定 2=已用 3=已释放 4=已过期 |
| source_order_id | BIGINT | 获取来源订单（购买时），可空 |
| lock_order_id | BIGINT | 锁定的订单，可空 |
| received_at | DATETIME | 领取/购买时间 |
| expire_at | DATETIME | 过期时间 |
| used_at | DATETIME | 使用时间，可空 |
| create_time | DATETIME | — |
| update_time | DATETIME | — |

**索引**：`(user_id, status)`、`(lock_order_id)`、`(template_id, user_id)`。

### 2.13 file（图片/文件元数据）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| biz_type | VARCHAR(20) | 业务类型：poster/avatar/seat_map |
| biz_id | BIGINT | 绑定业务 ID，可空 |
| original_url | VARCHAR(500) | 原图 URL |
| display_url | VARCHAR(500) | 展示图 URL |
| thumb_url | VARCHAR(500) | 缩略图 URL |
| size | INT | 大小(KB) |
| is_orphan | TINYINT | 是否孤儿图 0=否 1=是 |
| create_time | DATETIME | — |

**索引**：`(biz_type, biz_id)`、`(is_orphan, create_time)`。

### 2.14 stock_audit（库存变更审计）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | — |
| target_type | VARCHAR(20) | tier/coupon_template |
| target_id | BIGINT | 目标 ID |
| before_qty | INT | 变更前 |
| after_qty | INT | 变更后 |
| operator | VARCHAR(50) | 操作人 |
| remark | VARCHAR(200) | 备注 |
| create_time | DATETIME | — |

**索引**：`(target_type, target_id, create_time DESC)`。
