# TicketGo — 前端设计

> 版本：v0.1
> 技术栈：Vue3 + Vite + Pinia + Vue Router + Element Plus + Axios
> 定位：用户端 11 个页面（美观、可演示、部署云）；管理端仅 API（可选简单页面，演进点）

---

## 一、技术选型与工程约定

| 项 | 选型 | 说明 |
|---|---|---|
| 框架 | Vue3（Composition API + `<script setup>`） | — |
| 构建 | Vite | 开发快 |
| UI 库 | Element Plus | 企业级美观，少写 CSS |
| 状态 | Pinia（持久化插件） | 登录态/购物车/订单 |
| 路由 | Vue Router | 路由守卫（登录拦截） |
| 请求 | Axios（统一封装拦截器） | 注入 Token、统一错误处理 |
| 实时 | 轮询 / SSE / WebSocket | 秒杀结果、订单状态 |
| 座位图 | SVG 或绝对定位 DOM | 按坐标渲染 |

**统一约定**：
- 请求拦截器：自动带 `Authorization: Bearer {accessToken}`。
- 响应拦截器：401 自动刷新 Token 并重放；刷新失败跳登录。
- 图片：列表用 `thumb_url`，详情用 `display_url`。
- 全局：Loading/Skeleton、Toast、空状态、错误边界。

## 三、逐页推演（v1 → 问题 → 迭代）

### P1 登录/注册
- **v1**：手机号 + 密码/验证码 → 登录。
- **问题**：图形验证码展示？验证码刷新？短信倒计时？错误提示？
- **迭代 v2**：
  - 图形验证码：`GET /captcha` 拿 `{captcha_id, image_base64}`，点击图片可刷新；提交"发短信"时带 `captcha_id + 输入`。
  - 短信按钮：点击后 60s 倒计时；Mock 环境提示"验证码见后端日志"。
  - 双 Tab：密码登录 / 验证码登录。
  - 校验：手机号格式、密码强度、失败 Toast。
- **收敛**：双登录切换 + 图形验证码前置 + 倒计时防连点。

### P2 首页
- **v1**：演出卡片列表。
- **问题**：列表图太大 → 慢；无搜索/筛选；无分页/空态。
- **迭代 v2**：缩略图卡片（缩略图 URL）→ 搜索框 + 分类 Tab + 状态筛选 → 分页/无限滚动 + 骨架屏 + 空状态。
- **收敛**：`thumb_url` 列表 + 搜索/筛选 + 分页 + Skeleton。

### P3 演出详情
- **v1**：海报 + 简介。
- **问题**：场次/票档怎么选？开票倒计时？购票入口分流？
- **迭代 v2**：
  - 顶部海报（`display_url`）+ 演出信息；
  - 场次选择（时间/场馆）→ 票档表（价格/余票）；
  - 选购票模式："免选座抢票" → P4；"选座购票" → P5；
  - 未开票：开票倒计时 + "预约提醒"按钮；
  - 已售罄：按钮置灰。
- **收敛**：场次-票档联动 + 两种购票入口 + 开票倒计时/预约。

### P4 秒杀抢票
- **v1**：一个大"抢票"按钮。
- **问题**：重复点击？排队？结果如何反馈？选券？
- **迭代 v2**：
  - 开票倒计时（**服务端时间为准**，前端仅展示）；
  - 抢票按钮：点击后置灰 + Loading，防重复提交；
  - 排队：高峰期显示"排队中…"；
  - 结果：成功 → 跳订单详情支付；失败 → Toast 原因；
  - 选券：抢票前/结算页展示可用券（抵扣预览）。
- **迭代 v3**：
  - 结果反馈用 **轮询 or WebSocket**（异步落单，下单结果非即时）；
  - 按钮文案随状态变化（未开票/抢票/已抢完）。
- **收敛**：服务端校准倒计时 + 防重提交 + 排队提示 + 异步结果轮询/WS + 选券。

### P5 选座
- **v1**：点格子选座。
- **问题**：座位图怎么画？并发冲突？锁座倒计时？价格？
- **迭代 v2**：
  - 座位图用 **SVG/绝对定位 DOM**，按 `x,y` 坐标渲染；票档分区不同颜色；图例（可售/已选/已售/锁定）；
  - 点选 → 调 `POST /seat/lock` 锁座；被抢先 → 提示"座位已被选"并刷新；
  - 锁座倒计时（短，如 5 分钟）→ 超时释放并提示；
  - 底部已选座位 + 金额 + 选券 + 去结算。
- **迭代 v3**：大场馆座位多 → **按需渲染/虚拟化**；断线重连后重新拉取座位状态。
- **收敛**：坐标渲染 + 锁座交互 + 冲突提示 + 锁座倒计时 + 选券结算。

### P6 购物车
- **v1**：列表 + 合计。
- **问题**：只服务非秒杀场次；数量/删除；失效项。
- **迭代 v2**：勾选结算、数量增减、删除；失效/下架项标灰不可结算。
- **收敛**：非秒杀场次可用；勾选结算；失效处理。

### P7 订单列表
- **v1**：订单卡片列表。
- **问题**：状态筛选、分页、待支付入口。
- **迭代 v2**：状态 Tab（全部/待支付/已支付/已取消/已退款）+ 分页 + 卡片操作按钮（支付/取消/详情）。
- **收敛**：状态筛选 + 分页 + 操作入口。

### P8 订单详情
- **v1**：订单信息。
- **问题**：支付倒计时、电子票、退款。
- **迭代 v2**：
  - **支付倒计时**（15 分钟，服务端 `pay_expire_at` 为准），到期自动刷新为"已取消"；
  - 待支付 → 支付按钮（Mock 支付）；已支付 → **电子票二维码/票码**；可退款 → 退款按钮；
  - 明细展示（票档/座位/用券/实付）。
- **收敛**：倒计时 + 支付 + 电子票 + 退款 + 明细（含券抵扣）。

### P9 券中心
- **v1**：券列表。
- **问题**：限量券/不限量券差异；领取 vs 购买；券图片。
- **迭代 v2**：
  - 券卡片（图片/名称/门槛/优惠/有效期）；
  - 限量券 → "立即领取"；不限量购买券 → "购买"（跳下单）；
  - 已领/已购 → 置灰"已领取/已达上限"。
- **收敛**：券卡片（含图片）+ 领取/购买分流 + 状态置灰。

### P10 我的券包
- **v1**：券列表。
- **问题**：状态分类。
- **迭代 v2**：Tab（未用/已用/已过期）+ 券状态样式（灰化）。
- **收敛**：状态 Tab + 状态样式。

### P11 个人中心
- **v1**：信息展示。
- **问题**：头像/昵称/改密码。
- **迭代 v2**：头像上传（调 `/file/upload` biz_type=avatar）、昵称编辑、改密码弹窗（旧/新/确认）、我的收藏/提醒入口。
- **收敛**：头像/昵称/改密码 + 收藏/提醒入口。

## 八、工程结构与状态管理

### 目录结构
```
src/
├── api/            # 各服务接口封装（user/product/seat/cart/order/coupon/file）
├── components/     # 复用组件（CountdownTimer/CouponCard/SeatMap...）
├── views/          # 页面（11 个）
├── stores/         # Pinia：user/cart/coupon
├── router/         # 路由 + 守卫
├── utils/          # request 封装 / ws 封装 / 时间校准
└── main.ts
```

### Pinia Store
| Store | 状态 | 说明 |
|---|---|---|
| `user` | token / refreshToken / profile | 持久化 localStorage |
| `cart` | items | 购物车（非秒杀） |
| `coupon` | availableCoupons（下单用） | 临时缓存 |

### 路由守卫
- 需登录页面（订单/购物车/券包/个人中心/选座结算）未登录 → 跳登录并记录来源。

### 请求封装（`utils/request.ts`）
- 请求拦截：注入 `Authorization: Bearer {accessToken}`。
- 响应拦截：`401` → 用 refreshToken 刷新并重放；失败 → 跳登录。

## 九、页面级详细规格

### P1 登录/注册
- **组件树**：`Form` + `CaptchaImage` + `SmsButton(60s倒计时)` + `Tabs(密码/验证码)`。
- **状态**：表单字段、图形验证码 captchaId。
- **接口**：`GET /captcha`、`POST /sms/send`、`POST /user/login`。
- **边界**：验证码错误→刷新；短信频率限制提示；手机号格式校验。

### P2 首页
- **组件**：`SearchBar` + `CategoryTabs` + `ShowCard(thumb_url)` + `Pagination` + `Skeleton`。
- **接口**：`GET /product/list`。
- **边界**：空结果空态；加载骨架屏。

### P3 演出详情
- **组件**：`Poster(display_url)` + `SessionPicker` + `TierTable` + `CountdownTimer(开票)` + `ReminderButton`。
- **接口**：`GET /product/{id}`、`/sessions`、`/session/{id}/tiers`。
- **边界**：未开票→倒计时+预约；售罄→按钮置灰；已结束→禁用。

### P4 秒杀抢票
- **组件**：`CountdownTimer(服务端校准)` + `SeckillButton(防重)` + `QueueTip` + `CouponSelector` + `ResultDialog`。
- **状态**：抢票中/排队中/结果。
- **接口**：`POST /seckill/{s}/{t}`、`WS /ws`（订阅 `/user/queue/notify`）、`GET /order/{id}`（兜底轮询）。
- **边界**：重复点击禁用；售罄提示；WS 断线→轮询；支付倒计时。

### P5 选座
- **组件**：`SeatMap(SVG)` + `Legend` + `SelectedSeats` + `CouponSelector` + `CheckoutBar`。
- **接口**：`GET /session/{id}/seats`、`POST /seat/lock`、`POST /coupon/available`。
- **边界**：同座冲突提示并刷新；锁座倒计时；断线重连重新拉取。

### P6 购物车
- **组件**：`CartList` + `Checkbox` + `QuantityInput` + `CheckoutBar`。
- **接口**：`GET /cart`、`POST /cart/add`、`DELETE /cart/{id}`、`POST /cart/checkout`。
- **边界**：失效/下架项标灰不可选；空车空态。

### P7 订单列表
- **组件**：`StatusTabs` + `OrderCard` + `Pagination`。
- **接口**：`GET /order/list`。
- **边界**：空态；各状态操作按钮（支付/取消/详情）。

### P8 订单详情
- **组件**：`OrderInfo` + `CountdownTimer(支付)` + `TicketQR` + `RefundButton`。
- **接口**：`GET /order/{id}`、`POST /order/{id}/cancel`、`POST /payment/pay`、`POST /order/{id}/refund`。
- **边界**：倒计时到期自动刷新为已取消；明细含券抵扣；电子票展示。

### P9 券中心
- **组件**：`CouponCard(图片)` + `ReceiveButton/BuyButton`。
- **接口**：`GET /coupon/templates`、`POST /coupon/receive/{id}`、`POST /coupon/buy`。
- **边界**：已领/已达上限置灰；购买量 ≤ 每人限购数。

### P10 我的券包
- **组件**：`StatusTabs(未用/已用/过期)` + `CouponCard`。
- **接口**：`GET /coupon/my`。
- **边界**：空态；已用/过期灰化。

### P11 个人中心
- **组件**：`AvatarUpload(ImageUpload组件)` + `NicknameForm` + `PasswordDialog` + 收藏/提醒入口。
- **接口**：`POST /file/upload`(avatar)、`PUT /user/profile`、`PUT /user/avatar`、`PUT /user/password`。
- **边界**：上传格式/大小校验；改密码验旧密码。
